## 对应修改

| 反馈 | 新版处理 |
|---|---|
| 两侧都做成粉色 | 恢复左侧粉色、右侧青绿色的波点云团，车尾也按两侧颜色衔接 |
| 车尾单一 | 增加白云、彩虹、两侧小角色、Cinnamoroll原作艺术字和紫底黄字车队网址；尾灯上方补Tarmac Works与IXO标志 |
| 尾翼色块单一 | 主翼改浅蓝底、白云轮廓，加入青色点缀、粉/黄气球和星星，端板保留紫色 |
| 尾翼字体不对 | 直接复用R8分层源文件中的Cinnamoroll艺术字，撤掉替代的系统手写字体 |
| 风挡上沿无横幅 | 在实际可涂的车身上沿窄边加入紫底黄字“72nd Macau Grand Prix” |
| 后轮上方单调 | 模仿R8加入倍耐力贴纸、IXO云团标志、彩色短条和流星；标志避开后机盖的水平散热口 |
| 倍耐力不像 | 改用Pirelli官方新闻站点图形，保留长P及真实字形，不再用普通斜体打字 |

## 验证范围与横幅位置

交付为4096×4096贴图、9层PSD、独立PNG/SVG素材与模板曲面预览。PSD的合成预览及可见图层重新合成都与游戏用PNG逐像素一致；安装ZIP保持`Customs/Cars`和`Customs/Liveries`目录关系，未附其他涂装的DDS缓存。

**尚未完成ACC游戏内加载和材质验证。** 预览不是游戏截图，轮胎和玻璃仍为简化辅助几何。首次载入请核对自动号码板、接缝、车尾开口附近的图案和实际光照。

ACC常规自定义车身贴图不能任意改写玻璃横幅；[模板作者的说明](https://felixdicit.com/acc-templates-custom-liveries/)明确区分了自定义横幅与游戏预设。因此本版紫色横幅严格放在模型原有的可涂车身上沿，没有在辅助玻璃上加一条仅供预览的假贴纸。玻璃本身的横幅仍需使用ACC内置选项；不将车身上沿效果称为已完成自定义玻璃横幅。
