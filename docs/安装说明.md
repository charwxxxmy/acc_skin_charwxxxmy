# 安装方法

1. 退出ACC，下载并解压安装包。
2. 将`Customs`合并到系统实际“文档”中的`Assetto Corsa Competizione`文件夹。
3. 不要放进Steam程序目录，也不要形成`Customs/Customs`嵌套。
4. 启动ACC，选择Ferrari 296 GT3、UNO Racing - Cloud Parade、36号，按显示名中的版本号定位。

v1.12沿用`ferrari296_cinnamoroll_cloudparade36_v111`目录，安装时替换同名v111文件，即覆盖游戏内v1.11。显示名为v1.12。

目录关系为`Customs/Cars/<标识>.json`及`Customs/Liveries/<标识>/decals.png`、`sponsors.png`和对应材质JSON。
